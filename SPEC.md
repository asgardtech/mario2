# Vision
Create an engaging and fun Mario-like game in the browser that offers platforming mechanics, enemies, collectibles, multiple levels, and character customization.

# Goals & Non-goals
### Goals
- Develop a playable platformer with basic jumping and moving mechanics.
- Introduce simple enemies with basic behaviors.
- Add collectibles like coins and power-ups.
- Design and implement at least two levels or environments.
- Provide a basic UI with score display, lives indicator, pause menu, and level timer.

### Non-goals
- Implement advanced physics engine beyond basic jumping.
- Include real-time AI for enemies.
- Add complex character customization features.

# Initial tech stack
- WebGL
- Three.js for easier 3D modeling and animation

# First milestone
Create a basic platformer with jumping and moving mechanics, including the initial level design and UI elements.

# Open questions
- How should we handle user input for character movement?
- What level of detail should be included in the first level's environment?
